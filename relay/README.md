# ممر Smart Ledger Pro

يُشغَّل مرة واحدة على حسابك، ويخدم كل عملائك. كل مركز يحصل على معرّف ومفتاح خاصين به،
والممر لا يستطيع قراءة أي بيانات لأنها مشفّرة بين المركز وفرعه.

## النشر (من جهازك، مرة واحدة)

```bat
cd relay
npx wrangler login
npx wrangler deploy
```

ينتهي الأمر بطباعة عنوان مثل:

```
https://smart-ledger-relay.<اسم-حسابك>.workers.dev
```

## الاستعمال

في كل مركز (جهاز العميل الرئيسي): «ربط الفروع عن بعد» ← الصق العنوان في
حقل **عنوان الممر** ← احفظ ← أعد تشغيل البرنامج.

بعدها كل رمز ربط جديد يحمل الممر تلقائياً، والفرع يلصق الرمز كالمعتاد بلا أي إعداد:
لا فتح منافذ، ولا IP ثابت، ولا DDNS، ولا VPN.

> الفروع المربوطة سابقاً بعنوان محلي تبقى كما هي. لتحويل فرع إلى الممر أصدر له
> رمز ربط جديداً من شاشة الفروع.

## الحدود والتكلفة

- الخطة المجانية: ١٠٠٬٠٠٠ طلب يومياً ≈ ٣٠ فرعاً بمزامنة كل ٦٠ ثانية.
- الاتصال الخامل لا يُحتسب (WebSocket Hibernation).
- عند التوسع: خطة Workers بـ٥ دولارات شهرياً تكفي أكثر من ١٠٠ فرع.

## التحقق من عمله

```bat
curl https://<عنوانك>.workers.dev/health
```

يُفترض أن يرد: `{"ok":true,"app":"smart-ledger-pro-relay","v":1}`
